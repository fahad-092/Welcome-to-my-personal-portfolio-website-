# Fahad Ahmad Portfolio

## Run locally
Open `index.html` in a browser.

## Customize
- Replace the email address in `index.html`.
- Add your real education, GitHub and LinkedIn links.
- Replace the project descriptions with your actual projects.
- Add a profile image later if desired.

## Publish on GitHub Pages
Create a GitHub repository named `username.github.io`, upload these three files,
enable Pages from the repository settings, and use the generated URL in your resume.
