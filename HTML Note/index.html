HTML Notes

Easy Hinglish explanations with practical examples.

01

What is HTML?

HTML ka full form HyperText Markup Language hai. HTML ka use webpages ka structure banane ke liye hota hai.

Simple words mein, HTML website ka skeleton hota hai. CSS design banata hai aur JavaScript functionality add karta hai.

Basic Example

<h1>Hello World</h1>
<p>This is my first webpage.</p>

Important Points

  • HTML is not a programming language.
  • HTML is a markup language.
  • HTML elements webpage ka structure banate hain.
  • HTML5 modern websites ke liye use hota hai.
02

HTML Document Structure

Har HTML webpage ek basic document structure follow karta hai. 

<!DOCTYPE html>
<html lang="en">

<head>
    <meta charset="UTF-8">
    <title>My Website</title>
</head>

<body>

    <h1>Welcome</h1>

</body>

</html>

DOCTYPE browser ko batata hai ki document HTML5 format mein hai.

03

HTML Tags

HTML tags webpage ke different elements create karte hain.

Tag Use
<h1> Main Heading
<p> Paragraph
<a> Link
<img> Image
<div> Container
04

HTML Attributes

Attributes HTML elements ke baare mein additional information provide karte hain. 

<img src="photo.jpg" alt="My Photo">

<a href="https://example.com">
    Visit Website
</a>

Yahan src, alt aur href attributes hain.

05

Semantic HTML

Semantic tags element ka meaning clearly define karte hain. Ye SEO aur accessibility ke liye useful hain. 

<header>
    Website Header
</header>

<nav>
    Navigation Menu
</nav>

<main>
    Main Content
</main>

<footer>
    Website Footer
</footer>

Practice Questions

Apni learning ko test karein.

01

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.
02

What is the difference between HTML and CSS?

HTML creates the structure of a webpage, while CSS is used to design and style that webpage.
03

What are Semantic HTML Tags?

Semantic tags clearly describe their meaning and purpose, such as header, nav, main, article, section and footer.
04

What is the purpose of the alt attribute?

The alt attribute provides alternative text for images, useful for accessibility and when images cannot load.
